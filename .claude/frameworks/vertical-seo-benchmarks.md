# Industry Vertical SEO Benchmarks

## Purpose
This framework provides benchmark data across key SEO metrics segmented by industry vertical. Agents and skills reference these benchmarks when evaluating site performance, setting targets, and contextualizing audit findings. Benchmarks represent typical ranges for established sites (2+ years, actively managed SEO).

## 8. Using Benchmarks in Practice

### Contextualizing Audit Findings
- Compare site metrics against the appropriate vertical and size tier
- A site performing below the "Minimum Competitive" threshold requires urgent remediation
- A site performing at or above "Strong" thresholds is well positioned; focus on optimization and gap closure
- Always note the benchmark source and date when citing benchmarks in reports

### Setting Realistic Targets
- Set 6 month targets at the next tier up from current performance
- Do not set targets above the "Industry Leading" tier unless the client has exceptional resources
- Account for the starting position: sites far below benchmarks will see faster initial gains
- Reference the organic traffic growth rates in Section 2 when setting traffic targets

### Limitations
- Benchmarks represent typical ranges, not guarantees
- Individual site performance depends on competition, content quality, technical foundation, and investment
- Benchmarks should be updated annually as industry averages shift
- Local market conditions, niche specifics, and business model differences can cause significant variance
