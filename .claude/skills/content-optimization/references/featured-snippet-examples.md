# Featured Snippet HTML Examples

## Paragraph Snippets

Target length: 40 to 60 words. Provide a direct, complete answer immediately after the question heading.

```html
<h2>What Is a Canonical Tag?</h2>
<p>A canonical tag (rel="canonical") is an HTML element that tells search engines
which version of a page is the preferred, authoritative version. It is placed in
the head section of a page and points to the URL that should be indexed, helping
to consolidate ranking signals from duplicate or similar pages.</p>
```

## List Snippets

Google extracts ordered and unordered lists. Structure content with clear list formatting after a descriptive heading.

```html
<h2>Steps to Audit Your Backlink Profile</h2>
<ol>
    <li>Export your full backlink report from Ahrefs or SEMrush.</li>
    <li>Filter out links from domains with a Domain Rating below 10.</li>
    <li>Identify links from irrelevant or spammy niches.</li>
    <li>Check for unnatural anchor text patterns.</li>
    <li>Flag links from known link networks or PBNs.</li>
    <li>Compile a disavow file for toxic links.</li>
    <li>Submit the disavow file via Google Search Console.</li>
    <li>Monitor new backlinks monthly for ongoing quality.</li>
</ol>
```

## Table Snippets

Tables are extracted for comparison and data queries. Use clear column headers and concise cell content.

```html
<h2>HTTP Redirect Status Codes Compared</h2>
<table>
    <thead>
        <tr>
            <th>Status Code</th>
            <th>Type</th>
            <th>Link Equity Transfer</th>
            <th>Use Case</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>301</td>
            <td>Permanent</td>
            <td>Full transfer</td>
            <td>URL permanently moved</td>
        </tr>
        <tr>
            <td>302</td>
            <td>Temporary</td>
            <td>Retained on original</td>
            <td>A/B test or short term change</td>
        </tr>
        <tr>
            <td>307</td>
            <td>Temporary</td>
            <td>Retained on original</td>
            <td>Method preserving temporary redirect</td>
        </tr>
    </tbody>
</table>
```
